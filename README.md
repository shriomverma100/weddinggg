# Wishlys Luxury Wedding Invitation Website

A luxury, elegant, minimalist digital wedding invitation website built with React, TypeScript, Tailwind CSS, and HTML5 Canvas.

## ✨ Features

- **Cinematic Opening Screen**: Fullscreen blurred background, glassmorphism invitation panel, circular couple monogram (`A | S`), and animated "Tap to Open".
- **Ceremonial Petal Shower**: High-volume, dual-side petal cannons (left & right) that shoot inward with realistic physics on tap, arc in mid-air, cascade down, and cleanly conclude.
- **Traditional Wedding Invitation**: Authentic double-bordered stationery design with corner flourishes and Lord Ganesha line art (`|| Shree Ganeshaya Namah ||`).
- **Couple Introduction**: Two-column portrait layout with arched frames sliding in from left and right with an animated central heart icon.
- **Interactive Scratch-to-Reveal Date**: Real HTML5 Canvas scratch-off surface supporting mobile touch gestures and mouse drag, auto-revealing on scratch.
- **Live Countdown Timer**: Four circular gold indicators counting down to January 1, 2027 in real-time.
- **Editorial Couple Story**: Minimalist quote card with sophisticated typography.
- **Vertical Event Timeline**: Connected timeline with active node markers, detailed event cards (Welcome Event, Mehndi, Sangeet, Main Pheras, Royal Reception), and Google Maps directions links.
- **Wedding Venue Card**: Dedicated card for Umaid Bhawan Palace, Jodhpur with directions link.
- **Note on Gifts, Family Compliments & RSVP**: Understated, minimal typography sections.
- **Fully Responsive**: Optimized for mobile, tablet (iPad), and desktop screens.

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **HTML5 Canvas** (Scratch-to-reveal & petal physics)
- **Lucide React** (Minimal line icons)
- **Google Fonts** (Cormorant Garamond, Allura, Montserrat)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
